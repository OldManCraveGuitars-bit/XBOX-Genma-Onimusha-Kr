# v0.8 원본 XBE 교체 후 한글 깨짐 수정

이 문서는 기존 v0.8 폴더용 추가 수정 기록입니다. 현재 배포는 [v0.801 통합 ISO 패처](../README.md)이며, 일본판 원본 ISO에서 직접 생성합니다. 아래 XBE를 별도로 교체할 필요가 없습니다.

원본 일본판 `default.xbe`로 교체하면서 빠진 한글 처리 기능을 복구하는 교체용 파일입니다. **v0.8 한글화 게임 폴더의 `default.xbe` 한 파일을 교체**하면 됩니다.

## 적용

1. 기존 게임 폴더의 `default.xbe`를 백업합니다.
2. [HDD Text Fix ZIP](https://github.com/OldManCraveGuitars-bit/XBOX-Genma-Onimusha-Kr/releases/download/v0.8/XBOX-Genma-Onimusha-Kr-v0.8-HDD-Text-Fix.zip)을 풉니다.
3. ZIP 안의 `default.xbe`를 v0.8 한글 게임 폴더 최상단에 넣어 기존 파일을 교체합니다.
4. 나머지 한글화 데이터는 그대로 사용합니다. 이미 일본판 원본 XBE로 바꾼 상태에서도 같은 방법으로 적용합니다.

게임 데이터 전체를 다시 패치할 필요는 없습니다. 순정 일본판 데이터에 이 XBE만 넣어 한글화하는 파일은 아닙니다.

## 수정과 검사

원본의 23개 섹션, 기존 헤더 크기, 섹션 이름과 페이지 참조 포인터를 유지한 구조로 한글 코드와 데이터를 배치했습니다. 게임 코드·한글 코드·문자열·그림 데이터와 원본 타이틀 아이콘은 보존했습니다. HDD 매체 허용과 4KB 파일 끝 정렬을 보정했습니다.

본문 3,768페이지를 포함한 **5,219개 네이티브 출력 조건**이 정상 한글판과 동일합니다. 순정 원본 XBE와의 글자 출력 대조군 19건에서도 차이를 확인했습니다. 글리프 초기화·해제, 메뉴·저장·아이템·선택지·문서·영상 자막·크레딧 12종 검사와 읽기 전용 코드 실행 검사가 통과했습니다.

이 결과는 CPU 함수와 데이터 검사입니다. **실기 부팅과 전체 플레이는 미검증**입니다. 앞서 배포한 단순 매체/정렬 보정 후보와 별개의, 원본 구조를 사용하는 한글 출력 수정 파일입니다.
