# r15 실기 호환성 데이터 검사

아래는 내부 개발본의 검수 기록입니다. 현재 v0.8 공개 배포물과 해시는 [HASHES.md](../HASHES.md)를 기준으로 확인하세요. 기록의 `GenmaKoreanTool-r15.exe`는 개발용 편집기이며, 공개 배포하는 Windows 패처와 별개입니다.

데이터 검사 중 **확대 한글 글꼴의 범위 밖 읽기 1종**을 확인해 수정했습니다. 원문 번역, 이미지, 자막 내용은 r14 그대로이며 배포 데이터 변경은 `default.xbe` 한 파일입니다. 아래 결과는 파일·주소·원본 x86 루틴 검사이며 실기 실행 결과를 뜻하지 않습니다.

## 확인한 문제와 수정

일본판 `0x16A0A0`의 P4 글꼴 변환은 첫 텍스처에서는 정상이나, 뒤의 축소 단계가 P4 원본을 바이트 단위 행처럼 읽습니다. 일본판 256×256 대조에서도 같은 동작을 재현했습니다. r14의 512×512 글꼴에서는 OIM 블록 끝을 **131,008바이트** 넘어 읽었습니다. 이것은 반드시 즉시 크래시한다는 뜻은 아니지만, 다음 데이터가 잘못된 축소 글꼴로 쓰이고 파일 끝 다음 영역을 읽는 원인입니다.

r15는 ID `0A0101`, `0A0102`, `0A0103`이고 512×512인 글꼴에만 원래 크기 텍스처 한 장을 생성합니다. 실제 글자 UV와 화면 크기는 유지했습니다. 첫 레벨 P4→P8 변환과 Xbox 원본 스위즐 함수 `0x1949A0`를 직접 실행하고 출력 픽셀을 대조했습니다.

| 검사 | 수정 전 | r15 |
|---|---:|---:|
| 확대 글꼴 원본 밖 읽기 | 131,008바이트 | 0 |
| 축소 단계 수 포함 텍스처 레벨 | 10 | 1 |
| GPU 픽셀 데이터, 정렬 전 | 349,525바이트 | 262,144바이트 |
| 사용한 변환 작업 공간 | 262,144바이트 | 262,144바이트 |
| 원본 작업 공간 한도 | 524,288바이트 | 524,288바이트 |

GPU 메모리 할당·잠금은 호출 경계에서 모사했습니다. CPU 변환과 스위즐은 원본 기계어 실행 결과입니다. ID 3종, 원본 256×256, 같은 크기의 다른 ID 분기도 검사했습니다. 원본 256 글꼴과 다른 이미지 경로의 기존 축소 동작은 바뀌지 않았습니다.

## 검사 결과

- XBE 섹션 24개: 주소 겹침 0, SHA-1 24개 일치, 엔트리/TLS/인증서/커널 import 116개와 스택 예약 유지. Microsoft 공식 서명은 변경된 헤더를 인증하지 않으므로 **서명 검사 우회가 가능한 Xbox 로더 환경 기준**입니다.
- 추가 코드 전 진입점의 직접 제어 흐름: 963명령 검사. 지원 범위를 넘는 SIMD/신형 CPU 명령과 섹션 밖 잘못된 호출 0.
- 실제 KRDATA 권한 READ/EXECUTE로 3398회 함수 실행: 쓰기 권한 위반 0. 메뉴·아이템·선택문·오프닝·암호·영상·크레딧 9종 검사 통과. 관측한 추가 스택 사용 최대 200바이트이며 전체 게임 최대치를 뜻하지 않습니다.
- 번역 LINK 239파일, 원본 raw 복사 3158개: 복사 경계·입력 보존·각 복사본 분리 통과. 최대 복사량 1,895,920바이트. 원본보다 복사량이 늘어난 22파일의 증가 최대는 1,296바이트입니다. 디스크에서 같은 문자열을 공유해도 실행 시 별도로 복사한다는 점을 반영했습니다.
- 변경 LINK 435파일과 OIM 팔레트 변형 4764개: 헤더·픽셀/팔레트 범위·치수 검사 통과. 확대 리소스 308개, 고유 확대 글꼴 93개 검사.
- ISO 1743파일, 1820디렉터리 노드: 검색 순서·순환·섹터 범위와 겹침 검사 통과. 삽입 489파일이 배포 데이터와 일치. 원본 ISO 전체 대조에서 허용 범위 밖 변경 0바이트.
- 배포 EXE로 문서 단독·전체 빌드·검증을 수행해 489파일 재현. r14와 비교한 데이터 변경은 XBE 한 파일뿐입니다.

## 64MB 메모리 판단 범위

Xbox는 CPU/GPU가 64MB를 공유합니다. 파일 크기만 더하거나 모든 방 파일을 동시 상주한다고 계산하지 않았습니다. 원본과 r15의 페이지 단위 상주 XBE는 각각 5,652,480 / 6,754,304바이트로, 추가분은 **1,101,824바이트(약 1.05MiB)**입니다. 원본 시작 시 고정 물리 할당과 64MB 제한 플래그, 64KiB 기본 스택은 유지했습니다. 추가 글꼴 변환은 기존 512KiB 작업 공간 안에 들어갑니다.

전체 게임의 CPU/GPU/음성/영상이 겹치는 **최대 작업 메모리와 할당 실패 가능성까지 정적 자료만으로 확정하지는 않았습니다**. 이번 검사는 128MB 환경이 필요하다는 근거를 발견하지 않았으며, 64MB 전체 경로 무고장을 보증하는 결과로 표기하지 않습니다. 함수 검사에서 GPU 드라이버와 영상 디코더 호출을 대체한 구간도 위 자료에 명시했습니다.

## 저장 매체 조건

게임 내부 파일의 가장 긴 이름은 20바이트, 상대 경로는 38바이트로 FATX 제한 안에 있습니다. 개별 파일 크기도 제한 안입니다. 다만 ISO 자체는 5,385,351,168바이트로 FATX 단일 파일 한도를 넘습니다. **게임 파일을 푼 폴더와 ISO 한 파일을 하드디스크에 넣는 방식은 구분해야 합니다.** 원본 ISO도 4GB를 넘으므로 새로 생긴 파일 손상은 아닙니다.
